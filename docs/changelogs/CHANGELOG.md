## [Unreleased]

### Added
- **`Jobs/` application tracker (Phases 1–2).** File-based job-application tracker: `Jobs/README.md` (workflow), `Jobs/_schema/` (`job.schema.json` + `status-flow.md`), and per-role folders holding `job.json` (structured record with weighted `fit` score, status, dates, next action, history), `posting.md` (archived JD), and `fit-analysis.md` (scored breakdown). Seeded with three Mercury roles (Staff Brand Designer ~4.5, Senior Product Designer / Accounting Integrations ~6.7, Staff Visual Designer / Design Systems ~5.3) and a Tampa Bay Sun FC stub.
- **Job tracker CLI** — `npm run job` / `node scripts/job.js`: `list`, `board` (grouped by status), `show <id>` (record + fit breakdown), `status <id> <status> [note]`, `note <id> <text>`, `next <id> <text>`, `add <company> <role>`. Zero dependencies. File-store layer in `scripts/lib/jobs.js` is shared code for the Express API + `/jobs` dashboard phases.
- **Job tracker API** — `/api/jobs` mounted on the existing Express server (`server/src/routes/jobRoutes.js` + `controllers/jobController.js`), reading/writing the same `Jobs/` files as the CLI (no MongoDB): `GET /api/jobs` (`?status=` / `?company=`), `GET /api/jobs/board`, `GET /api/jobs/:company/:role` (full record incl. rendered `posting.md` / `fit-analysis.md` / `notes.md`), `PATCH /api/jobs/:company/:role` (`status` / `priority` / `nextAction` / `resumeVariant`, appends history), `POST /api/jobs/:company/:role/notes`.
- **Cross-project workflow API** — `GET /api/workflow` (`server/src/routes/workflowRoutes.js` + `controllers/workflowController.js`, backed by `scripts/lib/workflow.js`) reads the memory snapshot, open-task count, and `[Unreleased]` changelog section for every project listed in `Jobs/_workflow-sources.json` (currently the Ross Resume repo and the Paintbrush Marketing repo). Also `npm run job workflow` on the CLI.
- **`/jobs` dashboard** — private React page on the client (`client/src/pages/Jobs/`), routes `/jobs` and `/jobs/:company/:role`, **not linked from the header nav**. Kanban board grouped by status with fit badges and priority; a detail pane with inline status/priority controls (PATCH), an add-note box (POST), a weighted fit scorecard, and `posting.md` / `fit-analysis.md` / `notes.md` / history tabs; a Workflow tab showing the cross-project snapshot. Dev-only (needs the local API). Tiny dependency-free Markdown renderer at `client/src/utils/miniMarkdown.js`.
- **Static fit-analysis report** — `scripts/build-jobs-html.js` (CLI: `npm run job html`) renders every tracked role into one self-contained, print-friendly `Jobs/jobs-report.html`: white/editorial styling (18px rem-based scale, 46rem measure), a "how the fit score works" methodology box, a ranked summary table, and per-role scoring tables showing weight × raw score → weighted contribution → total, plus strengths/gaps and links. The Express server serves it fresh on each request at `GET /jobs-report.html` (rebuilds from `Jobs/` per hit); the `/jobs` dashboard header links to it. `jobs-report.html` is gitignored (generated).
- **"Raising this score" plans** — new optional `improvementPlan` block in `job.json` (schema updated): a summary, a `targetScore`, and `actions[]` (`do` / `why` / `leverages` / `lifts` / `effort`). Rendered as a "Raising this score" block in both the report and the dashboard's Fit tab whenever present; each action is grounded in an existing Paintbrush asset or shipped product. Plans written for Mercury Staff Brand Designer (5 moves, ~4.5 → ~6.2) and Mercury Senior Product Designer / Accounting Integrations (5 moves targeting Polished UI craft + Product judgment, ~6.8 → ~8).
- **Tampa Bay Sun FC — Graphic Designer (Entry Level)** added to the tracker (`Jobs/tampa-bay-sun-fc/graphic-designer-entry-level/`), status `applied`, fit ~7.6 (strongest craft fit of the four; risk is being read as overqualified for an entry-level seat). `posting.md` is **reconstructed** from Leroy's spec concept board, not the live JD. `job.json` gained an optional `links[]` field (schema updated) pointing at the concept board in `Designs/Tampa Bay Sun Football Club/`.
